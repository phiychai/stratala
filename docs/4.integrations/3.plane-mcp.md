# Plane MCP Integration

This document describes the Plane MCP (Model Context Protocol) integration for
the stratala project.

## Overview

The Plane MCP server enables programmatic access to Plane work management
features through Kilo Code and VS Code.

## Configuration

### VS Code (`.vscode/mcp.json`)

```json
{
  "servers": {
    "plane": {
      "command": "npx",
      "args": ["mcp-remote@latest", "https://mcp.plane.so/http/mcp"]
    }
  }
}
```

### Kilo Code (`.kilocode/mcp.json`)

```json
{
  "mcpServers": {
    "plane": {
      "command": "npx",
      "args": ["mcp-remote@latest", "https://mcp.plane.so/http/mcp"]
    }
  }
}
```

## Available Tools

| Tool                       | Description                          |
| -------------------------- | ------------------------------------ |
| `list_projects`            | List all projects in the workspace   |
| `create_work_item`         | Create a new work item/ticket        |
| `retrieve_work_item`       | Get work item details                |
| `update_work_item`         | Update a work item                   |
| `list_work_items`          | List work items in a project         |
| `create_work_item_comment` | Add comments to work items           |
| `create_workspace_page`    | Create workspace documentation pages |
| `list_cycles`              | List project cycles                  |
| `list_modules`             | List project modules                 |

## Usage Example

Creating a work item via MCP:

```typescript
// List projects
const projects = await mcp__plane__list_projects();

// Create a ticket
const ticket = await mcp__plane__create_work_item({
  project_id: 'project-uuid',
  name: 'Ticket title',
  description_html: 'Ticket description',
});
```

## Authentication

The MCP server uses OAuth authentication with Plane. Ensure you are logged into
Plane in your VS Code or Kilo Code extension.

## Overview

The content discovery system provides three distinct experiences for users to
discover and consume content:

- **Home**: Algorithmic highlights, trending content, editor's picks, and
  cross-format featured content for casual visitors
- **My Feed**: Personalized subscriptions showing content only from creators the
  user follows/subscribed to
- **Explore**: Browsing and discovery tools including categories, topics, tags,
  creator directories, and search

## Database Schema

### User Follows Table

Tracks which spaces (tenants) users follow:

```typescript
user_follows:
  - id (primary key)
  - user_id (foreign key to users)
  - space_id (Payload ID of the space/tenant)
  - created_at
  - updated_at
  - unique constraint on (user_id, space_id)
```

### Content Views Table

Tracks content views for analytics and trending calculations:

```typescript
content_views:
  - id (primary key)
  - content_type ('post' | 'video')
  - content_id (Payload ID)
  - user_id (nullable, for anonymous views)
  - ip_address (nullable, for anonymous views)
  - viewed_at (DateTime)
```

### Content Likes Table

Tracks user likes on content:

```typescript
content_likes:
  - id (primary key)
  - content_type ('post' | 'video')
  - content_id (Payload ID)
  - user_id (foreign key to users)
  - created_at
  - updated_at
  - unique constraint on (content_type, content_id, user_id)
```

## Payload CMS Collections

### Videos Collection

Similar to Posts collection but with video-specific fields:

- `videoSource`: Select field ('upload', 'embed', 'url')
- `videoUpload`: Relationship to media (when source is 'upload')
- `embedCode`: Textarea for embed code (when source is 'embed')
- `videoUrl`: Text field for external URLs (when source is 'url')
- `thumbnail`: Upload relationship for video thumbnail
- `duration`: Number field for video duration in seconds

### Editors Picks Collection

Manually curated content for featuring on the homepage:

- `contentType`: Select ('post' | 'video')
- `post`: Relationship to posts (conditional on contentType)
- `video`: Relationship to videos (conditional on contentType)
- `featuredOrder`: Number for ordering (lower numbers appear first)
- `featuredAt`: Date when content was featured
- `notes`: Internal notes for editors

## Backend Services

### TrendingService

Calculates trending scores using a hybrid algorithm:

```typescript
trendingScore = engagementScore + recencyBoost + manualBoost

Where:
- engagementScore = (viewCount * 0.4) + (likeCount * 0.6)
- recencyBoost = 10 (if < 24 hours) or 5 (if < 168 hours) or 0
- manualBoost = 20 (if editor's pick) or 0
```

### FeedService

Manages personalized feeds based on followed spaces:

- `getFollowedSpaces(userId)`: Returns array of space IDs user follows
- `getPersonalizedFeed(userId, options)`: Returns mixed content from followed
  spaces
- Supports sorting by 'chronological' or 'engagement'
- Pagination support

## API Endpoints

### Home Page

**GET `/api/home`**

Returns mixed trending content and editor's picks:

- Merges trending content with editor's picks
- Editor's picks appear first (sorted by featuredOrder)
- Then trending content (sorted by trending score)
- Public endpoint (no authentication required)

### Personalized Feed

**GET `/api/feed`**

Returns personalized content from followed spaces:

- Requires authentication
- Query parameters:
  - `page`: Page number (default: 1)
  - `limit`: Items per page (default: 20)
  - `sortBy`: 'chronological' or 'engagement' (default: 'chronological')

**GET `/api/feed/spaces`**

Returns list of space IDs the user follows.

**POST `/api/feed/spaces/:id/follow`**

Follow a space (requires authentication).

**DELETE `/api/feed/spaces/:id/follow`**

Unfollow a space (requires authentication).

**GET `/api/feed/spaces/:id/follow-status`**

Check if user is following a space (requires authentication).

### Explore

**GET `/api/explore`**

Browse and discover content:

- Query parameters:
  - `search`: Search query string
  - `category`: Filter by category slug
  - `tag`: Filter by tag slug
  - `type`: 'post', 'video', or 'all' (default: 'all')
  - `limit`: Items per page (default: 20)
  - `page`: Page number (default: 1)

**GET `/api/explore/spaces`**

Returns list of public spaces for creator directory.

### Engagement

**POST `/api/content/:type/:id/view`**

Track a content view (anonymous or authenticated).

**POST `/api/content/:type/:id/like`**

Like content (requires authentication).

**DELETE `/api/content/:type/:id/like`**

Unlike content (requires authentication).

**GET `/api/content/:type/:id/like-status`**

Get like status and count (requires authentication).

## Frontend Components

### ContentCard Component

Unified component for displaying both posts and videos:

- Handles both content types with type discriminator
- Shows thumbnail/image with video play icon overlay
- Displays author, category, and published date
- Links to appropriate detail page (`/blog/:slug` or `/videos/:slug`)

### Pages

#### Home (`/home`)

- Public page (no authentication required)
- Displays editor's picks section
- Displays trending section
- Uses `useTrendingContent` composable

#### My Feed (`/my-feed`)

- Requires authentication
- Shows content from followed spaces only
- Sort toggle: chronological or engagement
- Empty state with "Discover Spaces" CTA
- Uses `usePersonalizedFeed` composable

#### Explore (`/explore`)

- Requires authentication
- Search bar for content search
- Type filters: All, Posts, Videos
- Category navigation menu
- Grid/List view toggle
- Creator directory section
- Uses `useFetch` with query parameters

## Composables

### useTrendingContent

Fetches trending content from `/api/home`:

```typescript
const { content, error, refresh } = useTrendingContent({
  type: 'post' | 'video' | 'all',
  limit: number,
  key?: string
})
```

### usePersonalizedFeed

Fetches personalized feed with pagination and sorting:

```typescript
const {
  content,
  count,
  totalPages,
  error,
  currentPage,
  sortBy,
  handlePageChange,
  handleSortChange
} = usePersonalizedFeed({
  limit: number,
  page: number,
  sortBy: 'chronological' | 'engagement',
  key?: string
})
```

### useFollowSpace

Manages following/unfollowing spaces:

```typescript
const { loading, error, checkFollowStatus, followSpace, unfollowSpace } =
  useFollowSpace();
```

### useContentView

Tracks content views:

```typescript
const { loading, error, trackView } = useContentView();
```

### useContentLike

Manages content likes:

```typescript
const { loading, error, getLikeStatus, toggleLike } = useContentLike();
```

## Features

### Trending Algorithm

Hybrid approach combining:

- Engagement metrics (views and likes)
- Recency boost for recent content
- Manual boost for editor's picks

### Follow System

Users follow "spaces" (tenants):

- One-to-many relationship (user can follow many spaces)
- Unique constraint prevents duplicate follows
- Used to filter personalized feed content

### Engagement Tracking

- **Views**: Tracked on article detail page load
- **Likes**: Toggleable on article detail page only (not on cards)
- Both support anonymous and authenticated users (likes require auth)

### Content Types

Unified content type system:

- `UnifiedContent` interface supports both posts and videos
- Type discriminator (`type: 'post' | 'video'`)
- Single `ContentCard` component handles both types

## Implementation Notes

### Authentication

- Home page is public (no auth required)
- My Feed and Explore require authentication
- Feed endpoints use cookie forwarding for server-side requests
- Backend routes use `middleware.auth()` for protected endpoints

### Caching

- Home page content cached for 60 seconds
- Feed content not cached (personalized, requires real-time data)
- Explore content can be cached based on query parameters

### Error Handling

- Graceful error states with user-friendly messages
- Empty states with actionable CTAs
- Error boundaries prevent full page crashes
